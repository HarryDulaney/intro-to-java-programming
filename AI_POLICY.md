# AI Usage and Contribution Policy 
## Overview

### We recognize that AI developer tools (such as GitHub Copilot, Cursor, ChatGPT, Claude, and local LLMs) are an integral part of modern software engineering. This policy clarifies how AI-generated and AI-assisted contributions are handled within this project to ensure code quality, security, and open-source license compliance.

# These exercises were solved 100% without the use of AI 
## We ask kindly that you only commit solutions that you made without the use of Agentic AI or a Copilot pilot or that you copy and pasted from Google (Old School AI). The reason for this policy is that we want you to get the benefit of this book that we did. We had to struggle through these exercises without a (correct) answer available many times. Tha was truly uncomfortable and frustrating sometimes but it made solving one so much more rewarding. So, at the end of the day I can only recommend what worked for me. And struggling through hard coding problems gave me the confidence and knowledge base to build a career in software engineering. So I don't want to rob anyone else of that experience.

# You can use AI for other things 
## That doesn't mean you can't use AI tools or Agents on this project. Just not for new exercise solutions. For example someone could clone this repo and then ask Claude to validate all the solutions in chapter 17. That is totally cool and appreciated! If you find bugs you could either create an Issue or you could fix it yourself and then make a pull request explaining what was the error and how you fixed it!
